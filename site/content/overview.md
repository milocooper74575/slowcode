# slowcode 是什么

slowcode 是 Rust 写的认知协作式 coding agent。

> 人创造未知，AI 实现已知。

它不追求把 AI 的自动化比例拉满，而是把两件事当成一等公民：人的认知负荷，以及人对代码的所有权。到了关键节点，它会停下来，把创造空间留给人类：先拆认知任务，再区分已知域、半已知域与未知域，跳过需要人判断的部分，只实现已经讲清楚的部分。

## 三条设计主线

- **认知协作**：Plan workflow 先输出证据包与认知任务分配表，再逐题访谈，把半已知域变成可执行决策，把未知域留给用户实现。
- **阶段门禁**：未批准不能 scaffold，未实现核心不能 continue，测试未绿不能 distill。门禁在代码里，不靠提示词。
- **可恢复运行**：会话是 JSONL，run 有状态机、预算、审批与模型调用归档；中断后先核对未知结果，再决定是否重试。
